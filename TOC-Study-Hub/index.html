A finite, non-empty set of symbols. e.g., Σ = {0,1} or Σ = {a,b,…,z}.

M = (Q, Σ, δ, q&sub0;, F) where:
Q — finite set of states  |  Σ — finite input alphabet
δ : Q × Σ → Q — total transition function (exactly one next state)

NFA → DFA (Subset Construction)
Unit 2
Algorithm
Given NFA M=(Q,Σ,δ,q&sub0;,F), build DFA N=(Q',Σ,δ',q&sub0;',F'):
• q&sub0;' = ε-closure({q&sub0;})  |  F' = all DFA states S where S∩F ≠ ∅
• δ'(S,a) = ε-closure(⋃{δ(q,a) | q ∈ S})
Step-by-Step
  1. Start state = ε-closure({q&sub0;})
  2. For each unprocessed DFA state S and each input a: compute δ'(S,a)
  3. ∅ → dead/trap state (self-loops, non-accepting)
  4. Any DFA state containing NFA accept state → DFA accept state
  5. Repeat until all states processed
⚠
Worst case: n NFA states → 2^n DFA states. In practice, usually far fewer reachable states. Only compute reachable states.

DFA Minimization (Mark Algorithm)
Unit 2
Distinguishable Pairs
p ≠ q (distinguishable) if ∃w: exactly one of δ-hat(p,w), δ-hat(q,w) ∈ F
p ≡ q (indistinguishable) if ∀w: δ-hat(p,w) ∈ F ↔ δ-hat(q,w) ∈ F
Mark Procedure (Table-Filling)
  1. Remove inaccessible states (unreachable from q&sub0;)
  2. Base: Mark (p,q) if one ∈ F and other ∉ F
  3. Iterate: For each unmarked pair (p,q) and each a ∈ Σ: if (δ(p,a), δ(q,a)) is marked → mark (p,q)
  4. Repeat step 3 to fixed point
  5. Merge all unmarked (indistinguishable) pairs → equivalence classes

Regular Expressions — Definition
Unit 3
Base Cases
∅ — empty language {}
ε — language {ε}
a (for all a∈Σ) — language {a}
Inductive Cases
If E, F are REs:
E + F → L(E) ∪ L(F) (union)
EF → L(E)·L(F) (concatenation)
E* → (L(E))* (Kleene star)
Operator Precedence
* (star) > concatenation > + (union)

ab+c means (ab)+c, not a(b+c)

Shorthand
R+ = RR* (one or more)
R? = ε+R (zero or one)
R^n = R·R·…·R (n times)

Equivalence of Regular Expressions
Unit 3
Definition
R1 ≡ R2 iff L(R1) = L(R2)
IdentityExplanation
R + ∅ = R∅ is the additive identity
Rε = εR = Rε is the multiplicative identity
R∅ = ∅R = ∅∅ annihilates concatenation
R** = R*Star is idempotent
ε + RR* = R*R* = ε + R+
(R+S)* = (R*S*)*Star distributes over union
R + R = RUnion is idempotent
(ε+R)* = R*Adding ε under star changes nothing

RE ↔ Automata Equivalence
Unit 3
Main Theorem
DFA = NFA = ε-NFA = Regular Expression
All describe exactly the class of Regular Languages
Thompson's Construction: RE → ε-NFA
Base: empty -> [s] epsilon -> [s] -e-> [f] a -> [s] -a-> [f] Union (R+S): e->[MR]->e [new_s]-> ->[new_f] e->[MS]->e Concatenation (RS): [MR] -e-> [MS] (connect accept of R to start of S) Star (R*): e (bypass) [ns]-e->[MR]-e->[nf] ^--e--/ (loop back)
FA → RE (State Elimination)
1. Add new global start and accept states with ε-transitions
2. Eliminate intermediate states: replace with equivalent RE on remaining arcs
3. Final RE = label on arc from global-start to global-accept

Answer

What is a Regular Language? Give 2 examples and 2 non-examples with justification.
1 MarkCO1
Answer
A regular language is recognized by a Finite Automaton (equiv: described by RE).
Examples: {w | w contains "00"}; {w | |w| is even}
Non-examples: {a^n b^n | n≥0} (needs counting); {ww | w ∈ {a,b}*} (needs memory beyond FA)
